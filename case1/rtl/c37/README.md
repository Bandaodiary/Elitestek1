# C37 独立资源优化版本

状态：**四项资源优化已于2026-09-15通过最终验收。** 当前v2通过v1逐拍/独立整数参考、三个模型完整矩阵/原生时钟小图、稳定Mosaic的640×480六帧原生仿真和实际PNR。资源为**41,318 XLR / 117 RAM / 121 DSP**，核心150MHz约束setup/hold +0.267/+0.026ns；同模型旧RTL为43,986/129/130，净少2,668 XLR、12 RAM、9 DSP。原生五个完成间隔最慢**23.314907 fps@名义150MHz**，采集最慢30.426556 fps，14次显示/8,601,600像素检查、零下溢/缺帧。进程已真实退出、私有仿真目录已清理；[独立终态](../../logs/r2_c37_stable_native_terminal_20260915a.log)。可作为后续集成的资源优化版本，C35/C36仍保留，不覆盖旧源文件。

以上不是板卡帧率或官方IP联合签核：CPU仍为AXI流量代理、DDR为行为模型；官方物理IP、完整CDC及板测继续作为后续工作。

## 改动及约束

| 候选文件 | 作用 |
| --- | --- |
| `c1_r2_partitioned_window_store.sv` | row1/2银行容量512或1024；row0共享分区不缩小，同步RAM读延迟保持不变 |
| `c1_r2_spatial_partitioned_feeder.sv` | 向下传递容量，按物理源行和C8分组检查形状；保持原窗口/权重调度 |
| `c1_r2_weight_store6.sv` | 真实24/48组偏置/量化寄存器表、六份权重SRAM；加载字ABI不变 |
| `c1_r2_cnn_row_shadow_engine.sv` | 1597位请求，公共权重通路、同步通道ID、偏置查表、完整参数写入租期保护 |
| `c37_compute6_indexed.sv` | 59位逻辑参数记录、8深队列；新增一级弹性解析后接原量化器，仍为96 MAC |
| `r1_bilinear_interp_rgb888.sv` | 9次差分乘法的双线性插值表达式，保留原四级弹性流水和两级Q12舍入 |

默认 `MAX_CHANNELS=24 / ROW_WORDS=512`。兼容配置可在仿真编译命令定义 `C37_MAX_CHANNELS=48`、`C37_ROW_WORDS=1024`，或直接覆盖算子引擎参数。数据字/总线地址宽度不变；24通道配置并不支持加载48通道网络，软件容量检查和硬件拒绝不能省略。

## 参数生命周期

参数表仅在引擎空闲、请求寄存器为空、计算事务全部退休时允许写入。每次FIRST把通道ID、掩码及残差标志写入FIFO；MAC结果出来后按对应记录解析量化参数。最终输出退休前参数表不得改变，复位丢弃事务但不清除参数存储。新一级解析增加**每次算子固定一拍启动/收尾延迟**，不增加归约拍数、不在连续计算请求之间插入空拍。本次同模型六帧观测最慢帧率由旧23.319344变为23.314907 fps，约−0.019025%；该差异包含仲裁相位变化，不能完全归因于固定一拍。

v1的RAM/DSP减少已测得，但增加LUT后PNR只比不同ROM的旧C35少557 XLR（历史粗比，不是公平净收益）。当前v2静态参数选择实际比v1再少2,477 XLR；完整v1计算模块保存在 `reference/`，不得与生产同名模块一起编译。同模型A/B、三个模型整机矩阵及稳定模型原生六帧均已完成；源码记录宽度和寄存器位数不能直接换算为物理FF或XLR。
