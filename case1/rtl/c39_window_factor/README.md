# C39 窗口选择网络分级实验

独立于正在验证的 one-hot 候选，不是生产 RTL。只将窗口返回侧的六选一改为“物理行内奇偶选择 → 三行选择”，尝试共享奇偶选择逻辑。

两项请求槽、1,536 位窗口暂存、同步 RAM、II=2、回压、标签、复位、512/1024 行容量全部保留。非法行号 3 仍输出零。不削减 MAC、缓存或改变 CNN 数值。

入口：

- `golden/c39_window_factor_sources.py`：逐项生成对照和 49 源闭包检查；不修改父候选。

- `efinity/c1_ti60_c39_host_winfactor.xml`：同 one-hot 的纯 host 边界、模型和时钟约束，供短测通过后 MAP/PNR 比较。
