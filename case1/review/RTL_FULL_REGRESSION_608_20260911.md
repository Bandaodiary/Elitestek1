# 当前版本全量 Icarus 回归收尾

## 实测结果

本轮冻结生产 RTL，运行公共回归至进程正常结束：

`C1_REVIEW_FIXES_REGRESSION_PASS configurations=608`

退出码 0。608 是 runner 配置数，包含要求精确诊断且非零退出的负向配置，
不代表 608 个独立功能，也不等同于穷尽所有参数组合。

相对上次 598 配置，新增 RAM 参数/读写契约 7 配置、参数银行 2 配置、
阶段配置银行 1 配置。既有配置内还加强了 START 快照、CDC 停钟/协调
复位、参数及阶段配置的最后提交与取消碰撞检查。

原 C 驱动 host 与独立恢复接口 host 测试也重新通过。当前 ERROR_SEQUENCE
寄存器及其故障交错读取检查包含在此次 RTL 回归中。

## 文件与验证范围

回归脚本使用唯一临时 .vvp 和生成向量目录；finally 删除该编译映像和
已知生成向量，不生成波形。本次脚本正常退出；未额外保存大型仿真工程。

本轮没有执行整机 detached xsim/golden、Efinity 综合或板测，也没有在
RISC-V 上运行 C 驱动。独立测试中的可控背压、force 注入或简化时钟/视频
模型仍保留各自适用范围，不能用全量配置总数替代板级时序和数值吞吐证据。

下一项系统级验证应重跑当前 RTL 的整机数值与 APB 恢复链路；此前整机
通过记录早于 ERROR_SEQUENCE 改动，不能直接作为当前版本整机结果。
