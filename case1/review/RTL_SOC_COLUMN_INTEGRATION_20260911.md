# SoC 列读路径首次端到端接入

日期：2026-09-11。

## 生产 RTL 改动

`c1_r1_portable_soc` 新增默认关闭的 `ENABLE_TENSOR_COLUMN_READS`。开启后，adapter 使用三行原子列请求；原张量 AXI 客户端 6 保留给 `c1_tensor_mem_axi128_packing_bridge`，列读端点 `c1_column_cache_owned_exact_burst_shell` 使用新增的只读客户端。无预览时为客户端 7，有预览时为客户端 8，原预览客户端 7 不移动。

复用已有 N 路共享 AXI fabric，不新增临时仲裁层。新增客户端的写通道明确绑零，所有读返回由既有 fabric 的所有权机制路由。

新增 8-bit 标量未退休事务计数：

- 只在请求/响应真实握手时增加/减少，带溢出和无所有权响应的仿真断言。
- 列请求及列配置必须等待标量计数归零，防止读取尚未写完的特征图。
- 普通读写等待列端点静止，列请求优先；adapter 当前仍串行调度两类逻辑请求，不宣称计算/访存并行化。
- 端点忙状态、标量债务和共同取消状态纳入 tensor_cache_busy，继而进入 system_busy。
- 取消完成等待列端点 ACK、标量响应退休、无尚未接纳的标量请求和列端点静止，不把列端点 ACK 单独视为张量通路完成。

新路径取代 scalar burst client 分支，不与其同时实例化。现有 SoC xsim runner 增加 `-TensorColumnReads`；目前测试配置禁止与 `-TensorBurstRefill` 混用，避免旧分支专属探针失效。 packed writes 等选项的完整交叉验证仍待补齐。

## 首次复位问题与修复

列 RAM 的未知使能断言在 SoC 首个时钟触发，暴露 `arst_n` 声明初值为低、同步链尚未更新时复位输出可能未知的问题。`c1_reset_sync` 输出改为 `arst_n && sync_ff[STAGES-1]`：外部复位为低立即保证输出低，释放仍需完整同步链，不增加异步释放通路。

`tb_c1_reset_sync` 改为声明时将输入初始化为低，保留启动确定性及 64 次异步断言/三拍释放检查。测试通过。SoC smoke 共 25 配置通过，包括新增列读且有/无预览的 8/9 客户端组合。预览测试的硬编码客户端数相应调整，未放宽预览地址合法性或空闲流量检查。

## 验证边界

此分支已成为生产 top 内可选连接，不再只是分别验证 adapter 和端点。仍默认关闭。新分支需要进一步验证 APB 取消、在途写/读错误恢复、双帧连续运行、预览数据流并发、packed writes 和其他吞吐选项组合。结构 smoke 不等价于这些动态场景已验证。

本轮不运行综合/布局布线，没有新的物理资源或时序结论。增加一个 fabric 客户端会改变仲裁逻辑、端口和相关计数器宽度，不能视为零资源接入。原生 640×480 的 15 fps 尚未证明。

## 最终数值与周期证据

以下两个最终运行均 complete/exit 0，并经 `check_portable_soc_numerical_trace.py --require-video` 独立核验。两者采用相同训练参数、8×8 彩色 RGGB 输入、水平复用开启及其余默认选项：

| 项目 | 标量对照 | 新列读分支 |
| --- | ---: | ---: |
| RunId | soc_column_baseline_20260911_final | soc_column_golden_20260911_final |
| 共享 AXI 客户端数 | 7 | 8 |
| 成功计算任务周期 | 55,408 | 42,727 |
| 标量读事务 | 2,132 | 596 |
| 列请求/退休 | 无 | 512/512 |
| 写事务 | 836 | 836 |
| 逻辑读载荷 C8 数 | 2,132 | 596+512×3=2,132 |

成功计算任务周期减少 12,681 拍，约 22.9%，约 1.297 倍吞吐比。该统计是原 testbench 的计算 job 起止区间，不包含完整摄像头采集与显示刷新周期；也不是相同物理时钟实现已经达成的证明。新分支同时改变列返回粒度、补行链路和 fabric 客户端，不能将差异当成单项消融结果。

两者均核验 inputs=64、stages=22、C8_results=836、DDR_pixels=64、raw_pixels=64、styled_pixels=64。最终列版本另外通过 15 项日志破坏负测试，覆盖未知值、错误值、缺失/重复结果、DDR 错误、颜色/fixture 错误和显示像素缺失；检查器拒绝这些无效日志。

`soc_column_20260911_a` 是早期普通训练参数功能通过运行；`soc_column_golden_20260911_a` 是增加计数前的彩色数值通过运行，二者不替代上述最终数据。四个运行的临时目录均已确认不存在。WMI 隐藏 worker 与 Vivado 不绑定 Codex Windows job；保留的仅为小型状态及追踪日志。

完整 RTL 回归未重跑；本轮 Icarus 为 25 个 SoC smoke 配置和 1 个复位同步器配置。生产取消/多帧/并发组合仍按上节列为未完成，不用单帧成功掩盖这些缺口。
