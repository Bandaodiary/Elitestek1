# 参数银行提交边界与 RAM 消费者回归

## 补齐回归入口

此前参数银行和阶段配置银行 testbench 不在公共 Icarus runner 列表中，
不代表其不能由 Icarus 仿真。检查后确认两者自行生成激励、不依赖外部
工件，新增明确 PASS 门槛后均可执行。

- 参数银行：1056 个 128-bit word，完整加载/读取、双银行切换、提前 LAST、
  缺失 LAST、取消、并行读取旧银行及重新加载。
- 阶段配置银行：40 条命令、4 次提交、6 次错误、2 次取消、46 次读取；
  命令/读取背压、提交与读取重叠、generation 回绕检查。

## 新增边界

参数银行原 abort 场景在第 73 个索引取消。新增 ABORT_FINAL=1 时，先正常
写入前 1055 个 word，再在最后一拍同时给出 valid、last 和 abort。
若没有取消，这一拍本应提交新银行；测试要求不接纳该拍、只报告 aborted、
不报告 done/error，旧 active bank/generation 保持，并完整读回旧参数。
随后无复位重新加载，检查新银行提交和每一拍读取旧银行的数据正确。

普通/最后一拍取消两配置均通过，退出码 0。阶段配置银行独立 1 配置通过。
未发现本次范围内需修改的生产逻辑。该结果验证了公共 RAM 新增参数断言
对这两类实际消费者不会误报，但不代替整机、全量回归、综合或板测。

仅改 testbench 与公共 runner；新增入口会在后续全量回归中自动执行。
