# R2-C12：RGBX32 帧存储与连续 CNN 帧调度

更新：2026-09-13。C12 是独立命名的新主线；R1、C5～C11 的执行 RTL 保留为备选，不覆盖原 SoC。

当前结论：原生六帧全链与 Ti60 I3 150MHz 核心实现已通过，四个连续完整负载间隔最慢 **15.31fps**，最小周期余量 **2.05%**。仍是有限行为模型仿真，不是长期稳态或板测保证。六帧结果见第9节；第7/8节保留早期进度与三帧结果。

## 1. 本阶段为何调整架构

C11 的真实视频联合运行 `c11_video_xsim_native_20260913_a` 已成功结束，全部三次 CNN、实际采集写入、原图/结果配对显示及总线排空通过。它使用 640×480、30 fps 采集、720p60 双图、CPU 读写竞争，DDR 模型最多每两个核心周期提供一次合计 128-bit 读或写服务，每 burst 延迟 20 周期。核心参考频率为 150 MHz。

三次 CNN 分别执行 9,544,913、11,042,464、11,161,357 周期。第一帧显示尚未持续运行，属于预热；第三次执行本身约 13.44 fps，但相邻结果完成间隔为 **15,573,978 周期，即 9.63 fps**，未达到 15 fps。该值是有限次全负载仿真的实测间隔，不是长时间板测帧率。

除 DDR 竞争外，三原图/两结果槽也形成停顿：第二次 CNN 在 22,872,835 周期完成，错过 22.5M 周期的显示换帧点；待 25M 周期可切换前台时，采集恰好先回收唯一 READY 原图。第三次 CNN 必须等待新采集结束，到 27,285,456 周期才启动，额外空等 4,412,621 周期。单纯增加 MAC 无法消除这一等待。

因此 C12 同时压缩 RGB 外存占用、增加独立帧所有权容量；不降低采集/显示频率，不改模型或数值精度。

| 新增 RTL | 职责 / 连接 |
| --- | --- |
| `c1_r2_rgbx_row_read.sv` | C9 AXI 行读 DMA 外的 RGBX32→P2C8 转换；特征和参数直通 |
| `c1_r2_rgbx_row_write.sv` | P2C8→RGBX32 成对打包；C9 DMA 继续负责 burst、4 KiB、在途事务和真实 B 屏障 |
| `c1_r2_microstyle_rgbx_axi_graph.sv` | 将两个转换器接到保留的 C8/C9 CNN 图执行路径，启动时快照输入/输出槽 |
| `c1_r2_video_capture_rgbx32.sv` | 无 READY 的 RGB 像素入口，四像素打包、整行预存后 AXI 写出；错误帧丢弃并排空 |
| `c1_r2_video_scanout_rgbx32.sv` | 实际 DDR 原图/结果读出，四像素解包到不可等待的双图 ROI；欠载置错并输出黑色 |
| `c1_r2_video_rgbx_leases.sv` | 四原图/三结果槽状态与配对所有权；保护采集、CNN、待发布和前台显示 |

以上文件位于 `rtl/r2/`。外部仍是核心时域 RGB、显示 ROI 和规范化 ID0 CPU AXI；没有伪装成已连接物理摄像头、HDMI 或官方 Sapphire。

内部特征仍为 P2C8：每个 128-bit 逻辑字包含两个像素、每像素八个 signed INT8 通道。RGB 对应各 64-bit 半字的低三个字节，其他通道为零。96 MAC 阵列、重定标及全部 22 个节点不变；19 个张量写入节点继续与同一整数 golden 对照。

## 3. 外存 ABI 与地址

RGB 原图/结果在外存采用 RGBX32：每像素按地址递增为 R、G、B、0，一个 128-bit AXI 字装四像素。640×480 帧为 1,228,800 B，行跨度 2,560 B。两个 P2C8 逻辑字对应一个物理 RGBX32 字；仅输入/输出槽转换，参数和中间特征保持原布局。

RGB 行转换器将逻辑地址的 8 MiB 槽内偏移除以二，保留槽基址：`{address[31:23], 1'b0, address[22:1]}`。逻辑行首须 32 B 对齐、逻辑字数为非零偶数且不跨槽；非法命令本地拒绝，不发 AXI。图执行器快照槽号决定转换，避免执行期间软件改值影响正在进行的行。

默认 arena 为 `0x08000000`，槽大小 8 MiB：

| 用途 | 相对槽号 |
| --- | --- |
| 原图池 | 0、6、8、10 |
| 中间特征工作区 | 1、2、3 |
| 结果池 | 4、7、11 |
| 参数 | 5 |
| 联合测试 CPU 区 | 9 |

arena 独占区间为 `[0x08000000, 0x0E000000)`，96 MiB 地址预留，位于 256 MiB DDR 范围内；这不是片上 RAM 使用量。板级接入还须与 CPU linker、DDR 地址解码和缓存策略联合确认。

四原图槽允许 FRONT、旧待显示配对、CAPTURE 与一个新 READY 原图并存；第三结果槽使下一次 CNN 不必等待旧结果在垂直消隐时发布。前台原图与结果保持同一 tag，过期 READY/待发布配对由状态机明确回收，不能覆盖正在显示的帧。

新软件入口 `software/include/c1_r2_rgbx_video.h`、`software/src/c1_r2_rgbx_video.c` 检查 R2V2 ABI。C11 的 R2V1 驱动不能直接当作新布局驱动。MMIO FENCE 不等同于数据缓存 clean/invalidate。

RGB 写入逻辑 LAST 错误会污染整行并锁定后续命令，已拥有的物理事务继续排空；提前 LAST 的未提供尾部按零填充，可能实际写入，调用方必须丢弃帧并协调系统复位。此路径不冒充有效图像，也不承诺任意不响应 AXI 从机都能自动恢复。
