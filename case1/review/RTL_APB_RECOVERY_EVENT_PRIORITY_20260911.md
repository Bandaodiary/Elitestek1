# APB 恢复请求竞争与完成状态归属

本轮发现并修复 `c1_apb_csr` 完成状态优先级问题：旧恢复 done 脉冲与新
软件恢复请求同周期时，原代码让 done 置位获胜，软件可能把旧完成误认为
新恢复已完成。恢复 ready 在旧恢复完成边界可以重新有效，故不能假定该
组合永远不会发生。

修复后的优先级：复位清零；新软件请求接纳清零；否则完成置位；否则合法
W1C 清零。这样既阻止旧完成污染新请求，又保留完成事件与普通 W1C 碰撞时
“完成不丢失”的行为。非法请求不能清除或产生完成。
