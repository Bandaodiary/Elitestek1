# R2-C11 视频 DMA 开发记录（进行中）

上一目标阶段 C10 有实际进展：APB/fabric、竞争流量原生仿真及目标器件实现通过。
当前目标不收缩为算术核已完成：还需把真实视频服务、帧缓冲生命周期与官方平台接起来。
C10 及全部备用执行 RTL 保持不变，新模块/测试使用独立 video/p2c8 名称。

本轮路线：

1. 可映射同步 RAM 的小型 FIFO；不能用大型异步读寄存器 FIFO 冒充块 RAM 预算。
2. RGB888（R在[23:16]）不可回压采集 → 完整行预缓冲 → 保留 C9 AXI row writer。
   DDR 使用 P2C8：每像素64位，低字节依次R/G/B，其余零；两个像素合一个128位字。
   溢出/marker错误/取消使整帧无效；已经发出的行必须用已缓冲载荷完成并等真实B。
3. 保留 C9 row reader → RGB双像素FIFO → 不可等待的显示请求；先预取、按空间位置消费，
   欠载后本帧剩余置黑并报错，排空已发AR，不把迟来的像素平移到后续位置。
4. 帧缓冲生命周期与C10联合：采集完成后才供CNN，发布后按显示帧边界换帧，读写债务
   排空前禁止复用。小图持续双帧数值/错误恢复后再做原生竞争与Efinity增量资源评估。

以上为本阶段验收范围；实现与通过情况分开记录如下。物理CSI/HDMI/DDR IP、CDC约束和板测仍独立。
本轮RGB输入边界在ISP/Resize之后，不冒充已把官方多像素RAW10 CSI直接接入。
官方08实际Sapphire端口需按源码核对，不能把C10规范化ID0主口当作任意CPU AXI的通用插座。

沿用工具约束：无波形；仿真向量和EDA数据库私有、结束清理；Vivado只用检查Windows Job
为false的外层脱离运行器。只保留小日志，禁止复用运行ID，不计算文件哈希。

## 2026-09-13：联合系统验证

### 验收负载更正

原报告/赛题要求采集与预处理至少640×480@30fps，CNN至少15fps，显示720p60或1080p30并支持对照。
C10的15.28296fps是在15fps采集流量及单幅640×480显示流量下得到，**不能作为完整视频系统达标证据**。
C11原生测试采用30fps RGB采集，720p60画布中的两幅640×480原图/结果并排显示，另外保留CPU真实读写。
150MHz核心时域：采集每5,000,000周期；720p60像素事件74.25MHz（99/200），总时序1650×750，
有效双图区域1280×480，垂直居中；黑边不读DDR。输入事件在ISP/Resize/CDC之后，不代替真实CSI。

三次原生CNN执行用于区分首帧预热和开始持续显示后的吞吐；小图仍只用于功能/协议验证。
P2C8视频每像素8字节，持续平均采集73.728MB/s，双图显示294.912MB/s，CPU约9.375MB/s。
内存模型维持读写合计每两核心周期一个128位服务、每物理突发20周期起始延迟，不能分别给读写各一份带宽。

### 新增RTL，不覆盖C10/备用CNN

| 文件（`rtl/r2/`下） | 功能及边界 |
| --- | --- |
| `c1_r2_video_bram_fifo.sv` | 同步块RAM FIFO，两个输出暂存槽，共享预读信用，持续每周期一字；局部复位不取消AXI |
| `c1_r2_video_capture_p2c8.sv` | 不可回压RGB采集；完整行预缓冲后写DDR；溢出/marker/RESP错误令整帧无效并排空已拥有写事务 |
| `c1_r2_video_scanout_p2c8.sv` | 原图行与结果行顺序预取；固定节拍输出；欠载后本帧剩余置黑并排空读事务 |
| `c1_r2_video_frame_leases.sv` | 三原图/两结果缓冲的所有权，最新帧选择，原图与结果配对，显示帧边界换帧 |
| `c1_r2_video_csr.sv` | 新R2V1 APB控制ABI，启停新请求、计数、中断；停止不撤回已提交事务 |
| `c1_r2_video_cnn_system.sv` | 将以上模块与保留的C9 CNN、C10四客户总线互连组合；CPU口仍为规范化ID0，而非Sapphire原始多ID口 |

DDR arena默认从0x08000000开始，避开官方CPU低地址程序区；最终地址译码/链接脚本仍需平台联调确认。
新独立资源探针`efinity/c1_ti60_r2_video_system96.*`固定640×480，可能比C10运行时尺寸常量折叠更多；
它不含真实CPU、DDR PHY、ISP/Resize、HDMI/CSI和CDC，资源不能当成整板最终占用。
