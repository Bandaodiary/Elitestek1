# Task Packet：单份架构报告正文

- Scope：依据已确认八节框架，撰写一份比赛技术报告；不是学位论文或SCI多章全文。
- Exclusive owner：主代理。
- Files allowed to edit：`case1/report/chapters/赛题一_RTL架构设计与验证报告.md` 与本报告的plan/tables/figures；禁止修改RTL或既有结果。
- Required skills：writing-chapters、writing-core、evidence-driven-writing、experiment-results-planning、verification、peer-review；单份报告按一次完整章节交付。
- Files to read：`plan/evidence-map.md`、`plan/chapter-blueprints/report-blueprint.md`、已确认outline及E01—E19相关源片段。
- Required artifact：正文至少6000非空白字符、目标6000—8000中文正文字；参考文献与核心RTL路径可追溯。
- Argument chain：按blueprint的数据输入→算法→执行→内存/控制→输出→已有证据→集成边界展开。
- Rejection checks：无R0/R1混淆、无native echo冒充CNN、无DDR流式架构误写、无Fmax/资源跨器件外推、无VGG/教师蒸馏已完成的虚构陈述、无假数据。
- Placeholders：用户明确允许；用M/P编号并保留条件/单位。不得在同一指标旁填预计值使其看似实测。
- Validation：技能style_check、research_quality_gate草稿模式；本地标题/字数/文件链接/引文覆盖/关键数字检查。
